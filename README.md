# Созвездие — конструктор компетенций юного инженера (1–4 класс)

Игра-тестирование для 1–4 классов: 8 инженерных миров, суперсилы (Hard и Soft skills) и «Индивидуальный план развития инженерных компетенций».

## Публикация на GitHub Pages
1. Создайте репозиторий `Sozvezdie-1-4` в профиле abrinpro.
2. Загрузите `index.html` и папку `lib` (файлы из `lib` можно положить и прямо в корень — сайт найдёт их там).
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. Адрес сайта: https://abrinpro.github.io/Sozvezdie-1-4/

## Полезные адреса
- `…/?k=4.3` — ссылка для класса с меткой «4.3».
- `…/#dashboard` — результаты класса.
- `…/#teacher` — экран «Провести в классе» с QR-кодом.
