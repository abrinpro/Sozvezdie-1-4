# Созвездие — конструктор компетенций юного инженера (1–4 класс)

Игра-тестирование для 1–4 классов: 8 инженерных миров, суперсилы (Hard и Soft skills) и «Индивидуальный план развития инженерных компетенций».

Сайт: https://abrinpro.github.io/Sozvezdie-1-4/

## Публикация на GitHub Pages
1. Загрузите `index.html` и папку `lib` (файлы из `lib` можно положить и прямо в корень — сайт найдёт их там).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.

## Сбор результатов
- Ребёнок нажимает «Отправить результаты» — открывается Яндекс Форма «Созвездие 1–4 — результаты» с кодом результата в скрытом поле `code`. Остаётся нажать «Отправить». Имя не передаётся.
- Учитель в форме: «Ответы» → «Скачать» (XLSX или CSV) и перетаскивает файл на страницу «Результаты класса».
- Запасные способы: «QR для учителя», ссылка или файл с результатом.
- Адрес формы задан в `index.html`: `DATA.meta.collect.formUrl`.

## Полезные адреса
- `…/?k=4.3` — ссылка для класса с меткой «4.3».
- `…/#dashboard` — результаты класса.
- `…/#teacher` — экран «Провести в классе» с QR-кодом.
